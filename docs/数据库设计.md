## 关键约束说明

* **幂等唯一约束**：`pp_work_report.uk_pp_report_idempotency(work_order_id, operation_id, idempotency_key)`——数据库层兜底，杜绝重复报工产生脏数据；
* **幂等快照表**：`sys_idempotency.idempotency_key` 唯一，保存请求指纹与响应快照，同一 Key 重复请求直接回放首次结果；
* **库存不足拦截**：`mm_inventory_stock` 通过行级锁（`locking.py`）+ 事务扣减，扣减后可用量不得低于 0；
* **工单状态机**：流转合法性由 `order.WORK_ORDER_TRANSITIONS` 单一真源控制，非法流转在业务层直接拒绝。
