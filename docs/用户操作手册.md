# 用户操作手册

面向**车间管理员 / 班组长 / 操作工**的界面操作指引。
对应技术细节见 [接口文档](./接口文档.md) 与 [部署文档](./部署文档.md)。

---

## 1. 登录与角色

打开 <http://localhost:8000/>，使用下列任一账号登录（口令统一 `mes@2026`）：

| 账号 | 角色 | 能做 | 不能做 |
| --- | --- | --- | --- |
| `admin` | 管理员 | 全部功能，含基础数据维护、库存盘点 | — |
| `leader` | 班组长 | 工单下达/开工/完工/作废、质检处理、发料、看报表 | 基础数据维护 |
| `worker` | 操作工 | 看板、报工、查看设备/库存 | 下达工单、处理质检、发料 |

登录后左侧菜单栏可见项由**后端返回的权限码**决定，无权限的菜单与按钮不会显示；
即使直接调用接口，后端也会做接口级鉴权并返回 `4003`。

## 2. 车间看板（Dashboard）

路径：`#/`

* **顶部指标卡**：在制工单数、今日产量、良品率、设备稼动率。
* **设备实时状态**：每 2 秒自动刷新（SSE 长连接），无需手动刷新页面。
  卡片显示 运行 / 待机 / 故障 / 离线 与实时 OEE。
* **产量趋势**：近 N 天合格数与不良数折线图。
* **工单状态分布**：饼图。
* **告警区**：SPC 超限告警、库存低于安全库存预警。
* **手动采集**：点「立即采集」可立刻触发一次设备数据采集，用于演示时不用等 3 秒周期。

> 若右上角显示「缓存后端：memory」，说明当前 Redis 不可用、已自动降级为内存缓存，
> 实时刷新依旧可用，只是重启进程后缓存丢失。

## 3. 生产工单（Orders）

路径：`#/orders`

1. **新建工单**：选择产品、工艺路线，填写计划产量与优先级 → 生成草稿态（DRAFT）工单，
   系统按 BOM 自动展开物料需求。
2. **状态流转**：列表行内按钮由后端返回的可流转状态**动态渲染**，
   因此你永远不会看到一个"点了会被拒绝"的按钮。

   ```
   DRAFT →(下达)→ RELEASED →(开工)→ IN_PROGRESS →(完工)→ COMPLETED
   任意阶段 →(作废)→ CANCELLED
   IN_PROGRESS →(暂停)→ PAUSED →(恢复)→ IN_PROGRESS
   ```
3. **查看详情**：点工单号进入详情，可看到工序清单、每道工序的已完成/合格/不良数、
   物料需求与发放情况、报工流水。

## 4. 工序报工（Report Work）

路径：`#/reports-work`

1. 选择工单 → 选择工序 → 填写合格数、不良数（可填操作人、班次）。
2. 若该工序启用了 SPC，可填入 4~5 个实测值，系统会同时写入控制图并判异。
3. 点击**报工**提交。

**幂等演示**（本页最值得演示的功能）：

* 页面提供一个固定的幂等键输入框，默认形如 `report-wo1-op1-001`；
* 点「用同一幂等键重复提交」按钮连续提交两次；
* 第二次返回 `幂等命中，已回放首次结果`，数据库**只新增一条**报工记录；
* 刷新报工流水可以确认：数量没有翻倍，脏数据被拦住了。

超限与缺料都会被拦截并给出明确提示：

* 累计报工超过计划量 → `4009 报工数量超过计划剩余量`
* 物料库存不足 → `4009 可用库存不足`，且整笔事务回滚（工单数量不会半途变更）

## 5. 设备状态（Equipment）

路径：`#/equipment`

* 设备台账列表：编码、名称、所属产线、当前状态、最近上报时间。
* 稼动率卡片：按最近 24 小时（可调 1~720 小时）计算运行占比。
* 告警汇总：按等级统计故障告警。
* 状态由数采网关每 3 秒上报一次，写入 Redis（或内存缓存）并经 SSE 推送到页面。

---

## 6. SPC 控制图（SPC）

路径：`#/spc`

1. 选择产品 + 工序（如 `产品 1 / OP20`），加载 X̄-R 控制图。
2. 图上叠加三条参考线：中心线 CL、上控制限 UCL、下控制限 LCL（`markLine` 红色虚线）。
3. 超限点在图上以红色高亮，并在下方「判异清单」列出：子组序号、命中的准则编号、说明。
4. 页面底部可直接**录入新子组**：填 4~5 个实测值 → 提交 → 控制限与判异结果立即重算。
5. 若新子组命中判异，系统会**自动生成一张待处理质检单**（到质量检验页可见）。
6. 右上角显示过程能力 `Cp / Cpk` 与 σ 估计值。

## 7. 质量检验（Quality）

路径：`#/quality`

* 质检单列表：单号、来源（SPC 自动 / 人工报检）、产品、抽样数、状态。
* 状态流转：`PENDING → TESTING → PASSED / FAILED → CLOSED`。
* 录入检验记录：逐件填写实测值与公差带，系统自动判定合格/不合格。
* 填写结论后提交，结论会回写到工单的不良统计。

---

## 8. 库存管理（Inventory）

路径：`#/inventory`

* 库存余额：物料、仓库、账面数量、可用量、安全库存（低于安全库存标红预警）。
* 库存流水：发料 / 退料 / 盘点 / 报工扣减，全部留痕，可追溯单号与操作人。
* 发料：选择物料 + 仓库 + 数量 + 关联工单 → 提交；库存不足会被直接拒绝。
* 退料：退料量不会超过已发放量（自动取较小值）。
* 盘点调整：把账面数量调整为实测值，差额自动生成一条 `ADJUST` 流水。

---

## 9. 统计报表（Reports）

路径：`#/reports`

内置 8 张报表，支持切换统计窗口（默认近 30 天），表格与图形联动：

| 报表 | 看什么 |
| --- | --- |
| 工单进度报表 | 各工单计划量 / 完成量 / 完成率 |
| 良品率报表 | 按产品、按日期的合格数与良品率 |
| 设备稼动率报表 | 每台设备的运行/待机/故障时长与 OEE |
| 产量日报表 | 每日合格数与不良数 |
| 工序工时效率报表 | 实际工时 vs 标准工时 |
| 质量不良柏拉图 | 不良类型分布与累计占比（二八分析） |
| 库存周转报表 | 出库量、平均库存、周转次数 |
| 人员绩效报表 | 按员工/班次的产量与良品率 |

## 10. 演示路线（5 分钟走完闭环）

1. 用 `admin` 登录 → 看板确认设备数据在跳动（SSE 秒级刷新）；
2. 生产工单 → 新建一张工单 → 下达 → 开工；
3. 工序报工 → 报工 100 件、不良 2 件，并填 5 个实测值；
4. 点「用同一幂等键重复提交」→ 确认只产生一条记录；
5. SPC 控制图 → 观察新子组是否触发判异；
6. 质量检验 → 若自动生成了质检单，处理并填写结论；
7. 统计报表 → 打开良品率 / 产量日报，确认刚才的数据已统计进去。
